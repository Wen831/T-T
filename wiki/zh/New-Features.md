# 0.8.0 新增功能

本次发布把上游 TREK 4.3.0 的全部内容并入 Tourism-Team，并按 TT 自己的地图引擎、自己的高德（AMap）支持和自己的外观做了适配。以下都是 0.8.0 新增的；每项功能在本 WIKI 的常规位置也都有对应页面，可从各节末尾的链接进入。

## 公路旅行模式

本次最重点的功能。行程现在可以按「一次驾驶」来读，而不只是一串日期。

**位置：** 打开行程 → **计划** 标签 → 左侧栏顶部的切换器，在 **按天** 与 **公路旅行** 之间切换。

![公路旅行模式](assets/Roadtrip-Mode-zh.png)

切到 **公路旅行** 后，左侧栏由日程列表换成驾驶视图：整趟行程的总距离、总驾驶时间与停靠点数，然后逐日展开为路段与停靠点的链条，带有出发与抵达时间。

完整说明：[公路旅行模式](Road-Trip)。

## 沿线搜索

问「路上有什么」，而不是「附近有什么」。这是「下一个充电站在哪」这个问题的答案所在。

**位置：** 公路旅行模式 → 右侧 **沿线** 面板。

![沿线面板](assets/Roadtrip-Corridor-zh.png)

- **选类别** —— 加油、充电、服务区、露营地、住宿、餐饮、景点。可以同时选多个，它们共用一次查询。
- **选范围** —— 范围档位（默认 2 km / 5 km / 10 km）把搜索收窄到前方那一小段，或选 **全天** 覆盖整段行程。不选档位时默认覆盖前方 50 km。
- **搜索** 按行驶顺序返回结果，每行标明它离起点多远（沿路线多少公里）以及偏离路线多少，右侧 **+** 可直接加入行程。

搜索跟随你选择的地图引擎：启用高德搜索时会走高德，因此在 OpenStreetMap 数据薄弱的地方也能出结果。

完整说明：[公路旅行模式](Road-Trip)。

## 拖动路线改变行车路线

**位置：** 公路旅行模式 → 点击地图上画出的路线。

点击处会出现一个蓝色手柄，把它拖到别处，路线就会改从那里经过。

- **点击手柄** 选中它，圆点会出现光环。
- **拖动手柄** 改变路线。
- **删除手柄**：拖到地图左上角出现的红色 **拖到此处删除** 区域即可。桌面端也可以直接右键手柄删除。
- 手柄只在缩放级别 9 或更近时显示——缩得太远时拖一个手柄会让路线移动好几公里。

三种地图引擎（Leaflet、MapLibre/Mapbox GL、高德）都支持。

完整说明：[公路旅行模式](Road-Trip)。

## 从高德地图链接导入路线

沿线面板原本支持 Google Maps 路线链接，现在还支持高德链接。

**位置：** 公路旅行模式 → **沿线** 面板右上角 **⋯** 菜单 → **AMap (高德) route**。

粘贴 `ditu.amap.com/dir` 或 `uri.amap.com/route` 的链接，会按行驶顺序预览各停靠点，再选择要添加到哪一天。

高德链接使用 GCJ-02 坐标，而 TT 内部存储 WGS-84，导入时会做换算——地点会落在高德显示的位置，不会向东偏几百米。

完整说明：[公路旅行模式](Road-Trip)。

## 油耗与电耗续航

**位置：** 公路旅行模式 → **沿线** 面板底部 **驾驶设置** 卡片 → **车辆**。

填写车辆类型（燃油或纯电）、油箱或电池容量、百公里消耗、当前油量/电量与安全余量后，驾驶视图会标出每段路上「会耗尽」的位置，并提供 **搜索** 在该点附近找加油站或充电桩。

## 每日驾驶时限与时间窗

**位置：** 公路旅行模式 → **驾驶设置** → **每日行车时间** 与 **驾驶时间**。

可以限制每段与每天的行车分钟数，并设置每日起止时间。超出限制的日期会在驾驶视图中被标记，也可以按结束时间自动生成过夜停靠点。

- **沿路线结束** —— 到结束时间就在路上暂停。
- **在最后一个地点结束** —— 在下一个地点会超时之前停下。
- **恢复自动结束日** —— 清除手动设置的日界。

## 夜间停靠与夜间暂停

当天行程超过结束时间时，会在停车位置生成夜间停靠标记，标出是哪一晚、以及车停在某个地点还是路边。夜间停靠是自动的，没有单独开关。把某个停靠点标记为 **过夜** 是在该停靠点自己的面板里操作。

## 服务型停靠

加油、充电、服务区这类**属于路上的**、而不是目的地的停靠点，可以指定停靠类型，从而不计入当天的停靠点数——一天里在四个地点之间加一个充电站，仍然读作四个停靠点。

**位置：** 公路旅行模式 → 停靠点面板 → 停靠类型选择器。

## 避让类别

**位置：** 公路旅行模式 → **驾驶设置** → **避让**。

可以让路线规划避开 **收费路段**、**高速公路** 与 **轮渡**。是否可用取决于所选的路线配置。

## 风险与天气图层

**位置：** 公路旅行模式 → **驾驶设置** → **当前警告** → **显示危险区域**。

沿行程绘制当前天气与灾害提示。这些是**当前**提示，不是出行日期的预报，而且不会改变路线。

公路旅行模式下另有可选的日落与月亮标记图层。

## 文档同步

把行程的文档留在你已有的云盘里，让 TT 把行程与云盘目录配对，而不是把文件搬进 TT。

**位置：** 行程 → **文件** 标签 → 工具栏中的 **文档同步** 按钮。

> 只有当实例配置了文档提供方、或该行程已绑定某个云盘时，这个按钮才会出现——所以在新实例上，在管理员或所有者配置之前是看不到它的。已绑定行程的成员始终能看到，以便了解自己的文档放在哪里。

完整说明：[文档同步](Document-Sync)。

## Dawarich 对接

连接自建的 Dawarich 实例，读回你实际去过的地方。

**位置：** **设置** → **集成** → **Dawarich** 卡片。

![Dawarich 连接](assets/Dawarich-Settings-zh.png)

填写实例地址与 API 密钥，可选自动检查新的停留记录，然后保存。

TT 对 Dawarich 是**只读**的：TT 根据 Dawarich 的记录推荐日志条目、地点与国家，在你确认之前不会添加任何内容，也不会向 Dawarich 回写。已记录的轨迹也可以作为开关绘制在行程地图上。

> **中国大陆读者请注意：** Dawarich 自身的镜像基于 OpenStreetMap，在中国境内很可能无法正常使用。其他地区的实例仍可使用，TT 并未移除 Dawarich。

## 离线底座

IndexedDB 缓存、排队写入回放层、以及按视口预取的地点缓存，现在支撑着规划器，因此在网络较弱时平移地图和搜索仍然可用。

没有需要开启的设置项：离线行为是自动的，应用会说明当前正在使用缓存。参见 [离线模式与 PWA](Offline-Mode-and-PWA)。

## 收藏列表导出为文件

已保存的列表现在可以作为文件离开实例，也能导入到另一个实例。

**位置：** **收藏** → 打开一个列表 → 列表头部的 **导出**；旁边还有 **从文件导入列表**。

两种格式：TT 自己的列表文件（保留标签、颜色与「想法 / 想去 / 去过」状态）和 GPX（用于其他地图工具）。

完整说明：[收藏](Collections)。

## 费用收据

把收据的图片或 PDF 附到行程的一笔开支上。

**位置：** 行程 → **费用** 标签 → 新建或打开一笔开支 → **添加收据**。

收据与行程文件存放在一起，因此在 **文件** 标签里也能找到，并会随该笔开支一起删除。

完整说明：[费用](Budget-Tracking)。

## 协作聊天中的链接与图片

**位置：** 行程 → **协作** 标签 → 聊天。

- 粘贴图片到聊天，会直接上传并内嵌显示。
- 粘贴链接，会生成预览卡片。

## PDF 导出的行程地图

行程 PDF 现在可以带上地图。

**位置：** 行程 → **计划** → **导出** → **文档** → PDF。其中的 **路线总览** 一栏会把行程路线画成矢量地图，因此打印出的计划能看到整段行程的形状，不依赖瓦片服务器。即使地图绘制失败，文档其余部分也不受影响。

完整说明：[PDF 导出](PDF-Export)。

## 公共交通行程

按公共交通规划一段行程，并把真实班次拉进行程表。

**位置：** 行程 → **交通** → 添加预订 → **公共交通**。

填写出发与到达车站，TT 会获取可用班次。是否可用取决于实例是否配置了公交数据提供方。

## 手机端 Journey 时间轴

手机端 Journey 视图新增了 **日期滑条** 用于在行程各天之间移动，以及 **照片即卡片** 的版式，让每条条目以照片为主的卡片呈现，而不是一行文字。

**位置：** 在手机上打开一个旅程。参见 [旅程日志](Journey-Journal)。

## 地点搜索会标明来源

搜索结果现在会标出提供该结果的引擎——高德给出的标为「高德」，免费来源给出的标为 OpenStreetMap——而不再固定写死。实例配置了多个提供方时尤其有用。

参见 [地点与搜索](Places-and-Search)。

## 在管理面板中准备更新

**位置：** **管理** → 更新提示 → **准备更新**。

TT 仍会像以前一样检查新版本，现在新增了 **准备更新** 操作，在服务端执行更新准备并报告结果，而不只是打印一段让你自己复制的命令。连接器本身仍然在应用之外运行——TT 负责准备，不会替换自己的容器。

完整说明：[更新](Updating)。
