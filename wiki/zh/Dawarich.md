# Dawarich

Dawarich 是一个自建的位置历史服务。连接一个之后，TT 可以读回你实际去过的地方，并据此推荐日志条目、地点与国家——在你确认之前不会添加任何内容。

![Dawarich 连接](assets/Dawarich-Settings-zh.png)

> **插件。** 请先在 [管理：插件](Admin-Addons) 中启用 **Dawarich**。连接卡位于 **集成** 设置标签，而该标签本身也需要至少启用一个集成类插件才会出现。

> **中国大陆读者请注意。** Dawarich 自身的镜像基于 OpenStreetMap，因此在中国境内很可能无法正常使用，继续测试意义不大。如果你要记录在中国境内的出行，请改用内置引擎——见 [足迹（内置引擎）](Footprint)。

## 两个数据来源

卡片开头是**数据来源**选择：

| 来源 | 含义 |
|---|---|
| **外部 Dawarich 实例** | TT 从你自建的 Dawarich 服务器读取停留与轨迹——即下文所述的连接方式 |
| **TT 内置引擎** | 手机直接上报到 TT 本身，不涉及外部服务器。见 [足迹（内置引擎）](Footprint) |

本页余下内容都针对**外部**来源。内置引擎会从 TT 自己的档案喂给同样的界面——轨迹图层、建议、Atlas 推荐。

## 连接

**位置：** **设置** → **集成** → **Dawarich** 卡片 → **外部 Dawarich 实例**。

| 字段 | 说明 |
|---|---|
| **实例地址** | 你的 Dawarich 实例的基址 |
| **API 密钥** | 在 Dawarich 的 **账户 → API 密钥** 中查看。加密存储，之后不会再次显示 |
| **自动检查新的停留记录** | 关闭后，TT 只在你主动要求时才读取 Dawarich |
| **允许自签名证书** | 仅当你的实例使用服务器不信任的证书时才需要 |

**保存** 会存储连接；**测试连接** 会验证并给出结果，因此地址或密钥填错能在依赖它之前发现。

## TT 会做什么、不会做什么

TT 在这里是**读者**：

- 它读取 Dawarich 的到访记录与已记录轨迹。
- 它会根据读到的内容**推荐**日志条目、地点与国家。
- 在你**确认之前**，任何内容都不会加入行程；TT 也从不向 Dawarich 回写。

这是刻意的：一个自动勾选国家的轮询会覆盖你手动做出的决定。

## 地图上的已记录轨迹

已记录的轨迹可以画在行程地图上（计划视图）。

- **开关** 位于地图右下角的小药丸按钮，它也承载状态——正在加载、这些日期没有记录、实例不可达、或离线——因此你能看到*为什么*没有线，而不必猜。
- 线条画在计划路线**下方**，因为计划才是你正在编辑的东西。
- 它是**绘制**，从不**应用**：用记录来修正计划是另一个功能。

三种地图引擎（Leaflet、MapLibre/Mapbox GL、高德）都支持。
